PCB Defect Escape Rate: 2.3% → 0.08%

The Problem

Manual inspection at automotive quality standards is not viable

The client manufactured PCBAs for automotive interior control units — products with a zero-defect expectation from their Tier-1 customer. Four trained operators ran visual inspection on every board after reflow soldering, working 12–18 second inspection cycles with overhead loupe magnification.

At a 2.3% defect escape rate, roughly 1 in 43 defective boards was passing inspection and reaching the customer's assembly line. The Tier-1 issued a formal 8D report demanding root cause analysis and a measurable corrective action plan within 60 days — or face disqualification from future production runs.

The core issue: human visual inspection degrades with fatigue, lighting variation, and shift changeover. An automated system doesn't get tired, doesn't miss defects in the corner of the board at hour seven of a shift, and produces a traceable digital record for every board inspected.

Architecture

Edge inference with full ERP integration

4K camera array

Three 4K industrial cameras mounted on a custom aluminium gantry capture each board from overhead, 45° left, and 45° right — providing the depth information needed to catch lifted pins and tombstoned components that are invisible from directly above. Structured LED lighting with diffuse and raking modes controlled per inspection stage.

YOLOv8 fine-tuned on 14,000 images

We annotated 14,000 production PCB images spanning known defect types and good boards across multiple SKUs. YOLOv8n was chosen for latency headroom on the Jetson hardware — fine-tuned with custom augmentation pipelines mimicking production lighting variation, solder paste volume differences, and board orientation tolerances.

NVIDIA Jetson Orin NX — sub-100ms inference

All inference runs on-device on an NVIDIA Jetson Orin NX 16GB with TensorRT-optimised model weights. Mean inference time: 67ms per board at full 4K input resolution. The board never leaves the inspection station to reach a cloud server — latency is deterministic and production-line compatible.

PostgreSQL + React dashboard + ERP integration

Every inspection produces a timestamped record: board serial number, SKU, inspection result, defect bounding boxes (if any), and operator ID. Data is written to PostgreSQL and surfaced in a React dashboard with shift-level summary, defect trend charts, and SPC-style control charts. SAP integration via REST API posts pass/fail status directly to the production order record.

Predictive defect pattern detection

An unexpected benefit emerged after 6 weeks of production data: the dashboard's SPC control charts began showing correlated defect spikes — solder bridges and excess solder clusters appearing on specific PCB positions every 400–600 boards. Investigation traced this to stencil wear on the paste printer. Predictive maintenance replaced a reactive rework cost of ~€3,200 per stencil failure with a planned replacement cycle.
